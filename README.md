# chen-vv's Portfolio

This repository contains the code for my portfolio website, which can be viewed at [https://chen-vv.github.io/](https://chen-vv.github.io/).

## Available Scripts

In the project directory, you can run the following commands:

```
npm start               # Runs the app in development mode on http://localhost:3000

npm run deploy          # Deploys the app to production and updates the gh-pages branch

npx prettier . --write  # Formats the codebase
```
